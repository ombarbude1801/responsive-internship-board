# Responsive Internship Board

A beginner-friendly, framework-free internship listing interface built for the EdVyro Full Stack Development internship milestone.

## Features

- Semantic HTML structure
- Responsive layout for mobile, tablet and desktop
- Internship cards rendered with JavaScript
- Search by role/company
- Domain filtering
- Clear/reset controls
- Empty search state
- Error state
- Accessible labels and live result announcements
- Keyboard-friendly native form controls
- No external framework required

## Files

- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — internship data, DOM rendering and filters

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deployment

This project can be deployed using GitHub Pages, Netlify or Vercel.

## EdVyro submission

Set the GitHub repository to **Public**, then submit the public repository URL or deployed URL in the EdVyro Project URL field.
